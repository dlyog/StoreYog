# Synthetic shelf image

`indian-grocery-shelf.webp` is an AI-generated demonstration image, created with the built-in image generation tool for StoreYog. It depicts a fictitious Indian grocery shelf; it is not evidence of a real store, stock or product. No actual brands or people are depicted. The app labels demo captions as synthetic.

Generation prompt: realistic wide photograph of a modest neighborhood Indian grocery pantry shelf, straight-on; clear bags of white basmati rice on the bottom shelf, yellow lentils on the middle shelf, unbranded spice jars and tea packets above; warm ordinary indoor light; no people, logos, readable text, watermark or arrows. The app overlays separate owner-configurable arrows for each product.

The configured demo tenant receives six product associations with this shared shelf scene. Each association has its own description and marker. Registered businesses start empty and never receive demo media. Product uploads live in the ignored private `.runtime/product-images/` directory and are served only through authorization/publication checks.
